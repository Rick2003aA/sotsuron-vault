# 卒論の構成案

> [!summary] 現在の方向性
> 企業のDXへの取組を「未導入 → 導入開始 → 定着 → 展開 → 価値創出」という状態で整理する。各状態にいる企業の特徴を比較し、価値創出に向けて重要と考えられる組織的条件を検討する。

## 研究の問い

**主問い**

> 企業はデジタル技術を使ってどのような価値創出を目指し、その実現に向けた取組の各状態で、どのような組織的条件が重要になるのか。

**副問い**

> 企業の取組は現在どの状態に分布し、隣り合う状態の企業にはどのような特徴の違いがあるか。

## 分析の流れ

1. **DXによる「価値」を定義する**
   - 誰にとっての価値か、何が変われば価値を生んだと言えるかを整理する。
   - デジタイゼーション、デジタライゼーション、DXの違いも明確にする。
2. **企業の状態別の分布を調べる**
   - 「未導入」「導入開始」「定着」「展開」「価値創出」に該当する企業の割合を確認する。
   - これは一時点での分布であり、同じ企業が次の状態へ移った割合ではない。
3. **状態ごとの企業の特徴を分析する**
   - 戦略、人材、組織体制、成果測定方法など、比較する観点を設定する。
   - どの観点が状態の違いを説明するうえで有用かを検討する。この観点の設定を論文の独自性につなげたい。
   - 企業規模や業務の違いによる見かけ上の差を、できる範囲で区別する。
4. **隣り合う状態の企業を比較する**
   - 例えば、導入開始段階と定着段階の企業で、どのような特徴が異なるかを見る。
   - 差から「次の状態へ進む際に重要そうな条件」を仮説として抽出する。
   - 差があるだけで移行の原因とは断定せず、企業事例で取組の経過を検討する。
5. **企業が目指すべき姿を考察する**
   - 価値創出を一度実現するだけでなく、その先にどのような企業の姿が求められるかを、分析結果から考える。

## 産業の位置づけ

産業ごとのDX進捗を順位付けすることは研究の中心にしない。状態別に企業を分けた結果、産業に偏りがあるかを確認する。

現時点の仮説として、建設業・製造業の企業は前半の状態に、金融業・情報通信業の企業は後半の状態に多い可能性がある。ただし、これは未検証であり、同じ産業内の企業差も考慮する。

## 比較する企業の条件

隣り合う状態の企業を比べるとき、企業規模などの条件が大きく異なると、見つかった差を組織的条件の違いとして解釈しにくい。次のように、**揃える条件**と**比較したい特徴**を区別する。

| 扱い          | 項目                              | 方針                     |
| ----------- | ------------------------------- | ---------------------- |
| 優先して揃える     | 従業員規模、産業・業務の種類、調査年              | 同じ区分内で状態別の企業を比較する。     |
| データがあれば確認する | 売上高・総資産、設立年数、企業グループへの所属、既存のIT基盤 | 追加の層別比較や結果の解釈に用いる。     |
| 違いを調べる      | 戦略、人材の配置・育成、組織体制、部門間連携、成果測定     | 最初から揃えず、状態間の特徴として分析する。 |

規模の主な基準は従業員数とする。投資余力も重要だが、従業員数では直接測れないため、利用可能なら売上高・総資産などを補助的に確認する。資本金だけで現在の投資余力を判断しない。異なる調査の規模区分を混ぜず、各調査の対象企業・区分・分母を記録する。

同じ調査で「企業の状態」と「比較する特徴」を結びつけた集計、または企業単位の回答が利用できるかを確認する。別々の周辺分布だけから、同規模企業における特徴の差を推定しない。

## 先行研究との違いを確かめる

IPAには、回答企業をデジタイゼーション・デジタライゼーション・DXの3群に分け、各群の特徴と課題を比較した[「DX推進の段階毎の企業の課題と考察」](https://www.ipa.go.jp/digital/chousa/discussion-paper/dxwp2023-bestpractice.html)がある。状態別の分類・比較そのものを本研究の独自性とはしない。

まずこの資料の分類基準、比較項目、規模などの扱いを確認する。そのうえで、五つの状態に細分する意義や、同じ条件の企業間で何を新たに検討できるかを定める。

## まだ決めること

- **価値の定義**：顧客向けの新商品・サービス、既存事業の改善、生産性向上などをどう扱うか。
- **状態の判定基準**：各状態を、調査のどの設問や事例のどの事実で識別するか。
- **比較する観点**：戦略、人材、組織体制、成果測定などから何を優先するか。
- **利用できるデータ**：同じ調査で企業の状態と組織的条件を結びつけて比較できるか。
- **比較条件の実現性**：従業員規模と産業・業務を揃えたとき、各状態に十分な企業数が残るか。
- **先行研究との差**：IPAの3群比較に対し、五状態の分析で何を新たに説明できるか。
- **事例の選び方**：仮説を検討するために、どの企業の取組経過を調べるか。

## 論文の章立て案

1. **序論**：問題意識、研究目的、問い。
2. **概念と先行研究**：DXと価値の定義、状態区分、既存研究で分かっていること。
3. **研究方法**：状態の判定基準、資料、分析観点、事例の選定方法。
4. **状態別の分布と特徴**：各状態の企業割合と、戦略・人材・組織体制などの比較。
5. **隣り合う状態の比較と企業事例**：違いから立てた仮説と、事例による検討。
6. **結論**：価値創出に向けた条件と、DX時代に企業が目指すべき姿。
